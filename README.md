Afya Poa is a web-based digital health records portal developed as an 
academic project to demonstrate how Information and Communication Technology 
(ICT) can be applied to improve healthcare service delivery in Kenya.
The system proposes a centralized platform where patient medical 
records are stored digitally and accessed securely by authorized 
healthcare professionals such as doctors and pharmacists. 
Patients can view their medical history using a National ID number or, 
ensuring continuity of care across different healthcare facilities.
________________________________________
Project Motivation
In many healthcare facilities, patient records are 
stored using physical files which are prone to loss, 
damage, and mismanagement. This often leads to delayed 
treatment, repeated medical tests, and incomplete medical history, 
especially during emergencies.
Afya Poa aims to address this challenge by demonstrating a paperless, 
secure, and efficient digital alternative.


Key Features
Patient registration and digital medical records
Secure login and role-based access control
Doctor access to patient history, diagnosis, and treatment records
Pharmacist access to prescription and medication records
Patient access to view (read-only) medical records
Centralized database for improved data accuracy

Target Users
Patients
Doctors
Pharmacists
System Administrator

Technologies Used
HTML, CSS, JavaScript
PHP 
MySQL (database)

Project Scope
This project is a prototype and learning tool developed for educational purposes. It is not intended for 
real-world medical deployment but serves to showcase system design, database management, 
user roles, and data security concepts at secondary school level.
